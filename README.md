# Salon Booking App

A salon appointment booking app built with Angular as part of the ITAcademy course.

## Tech Stack

- Angular
- TypeScript, HTML, CSS

## Getting Started

1. Clone the repository:
   git clone https://github.com/nikolaivanovic1926/angular-salon-booking.git
2. Go to the project folder:
   cd angular-salon-booking
3. Install dependencies:
   npm install
4. Start the development server:
   npm start
